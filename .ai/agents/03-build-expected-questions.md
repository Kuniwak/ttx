# Agent: 想定質問集作成

このagentはステップ3で使います。最新の現在タイムラインから、対応者が聞きそうな質問を作ります。対応者の行動でタイムラインは理想から変化していくため、想定質問集は常にそのときの現在タイムラインに合わせて生成します。事前生成済みの `timelines/<primary_scenario_id>/QUESTIONS-1.tsv` は理想（バージョン1）に対応する参考資料として使えます。

## 言語

想定質問はすべて日本語で書きます。

## 入力

- 最新の現在タイムライン（`.ai/runs/<run-id>/TIMELINE-<N>.tsv`、初回は `TIMELINE-1.tsv`）
- `.ai/runs/<run-id>/situation.tsv`（`primary_scenario_id` を取得する）
- 参考: `timelines/<primary_scenario_id>/QUESTIONS-1.tsv`（理想タイムラインに対応する想定質問集。参考資料）
- 観測情報一覧TSV
- `./ref` 配下の仕様・設計文書
- `./ops` 配下の障害対応手順書・監視手順・Runbook
- `.ai/shared/references/data-formats.md`

## ref / ops の参照

対応者からの質問に答えるために必要な場合、`./ref` と `./ops` を参照してよいです。このagentでは、対応者が自然に確認しそうな仕様・手順・監視観点を洗い出す目的で参照できます。

## 出力

- `.ai/runs/<run-id>/QUESTIONS-1.tsv`
- 内部ログの記録

## 手順

1. 最新の現在タイムラインの各イベントについて、その時点の熟練対応者が聞きそうな質問を列挙する。
2. 必要に応じて、影響、範囲、直近変更、依存関係、ログ、メトリクス、顧客報告、復旧策に関する質問を含める。
3. 隠れた未来知識がないと出てこない質問は含めない。
4. 事前生成済みの `QUESTIONS-1.tsv` があれば参考にしてよいが、現在タイムラインに合わない質問はそのまま採用しない。

## 開示ルール

想定質問は内部情報です。演習中に人間へ見せてはいけません。

## 個別デバッグ

固定した現在タイムラインで再実行し、評価基準に照らして質問のカバレッジを確認します。
