# Agent: 想定回答集作成

このagentはステップ4で使います。想定質問に対する回答案を、最新の現在タイムラインにもとづいて作ります。対応者の行動でタイムラインは理想から変化していくため、想定回答集は常にそのときの現在タイムラインに合わせて生成します。事前生成済みの `timelines/<primary_scenario_id>/ANSWERS-1.tsv` は理想（バージョン1）に対応する参考資料として使えます。

## 言語

回答文はすべて日本語で書きます。

## 入力

- `.ai/runs/<run-id>/QUESTIONS-1.tsv`
- 最新の現在タイムライン（`.ai/runs/<run-id>/TIMELINE-<N>.tsv`、初回は `TIMELINE-1.tsv`）
- 参考: `timelines/<primary_scenario_id>/ANSWERS-1.tsv`（理想タイムラインに対応する想定回答集。参考資料）
- `.ai/runs/<run-id>/situation.tsv`（`primary_scenario_id` を取得する）
- 観測情報一覧TSV
- `./ref` 配下の仕様・設計文書
- `./ops` 配下の障害対応手順書・監視手順・Runbook
- `.ai/shared/references/data-formats.md`

## ref / ops の参照

対応者からの質問に答えるために必要な場合、`./ref` と `./ops` を参照してよいです。ただし参照は「ある情報が観測可能・開示可能か」を判断する目的に限ります。回答に使えるのは質問時点で観測可能な事実だけです。次に確認すべき手順・監視項目・調査方法といった"手がかり"は、手順書や仕様に載っていても回答に含めてはいけません（対応者自身に調べさせます）。

## 出力

- `.ai/runs/<run-id>/ANSWERS-1.tsv`
- 内部ログの記録

## 手順

1. `QUESTIONS-1.tsv` の `時刻` と `質問` 列を維持する。
2. `回答` 列を追加する。
3. 回答の作り方は `.ai/agents/07-handle-question-or-action.md`「質問・行動への応答方針」に従う（判断フロー＋述べる/述べない）。観測値はシナリオ（真因・`OBSERVATION.tsv`・現在タイムライン）と整合する範囲で生成して述べてよい（現在タイムライン作成の一部であり捏造ではない）。
4. 回答は観測事実を端的に書く（通常1〜3文程度）。前置きや繰り返しの要約は省く。ライブ応答（ステップ7）がこの回答を参考にするため、根元から簡潔にしておく。
5. 事前生成済みの `ANSWERS-1.tsv` があれば参考にしてよいが、現在タイムラインに合わない回答はそのまま採用しない。

## 開示ルール

回答案は開示レビューが終わるまで内部情報です。

回答案は観測可能な事実の提示に留め、GM 自身の推測・仮説、次にやるべき切り分け・調査手順の提案、特定の結論への誘導を含めません（推論は対応者に委ねる）。

## 個別デバッグ

固定した質問集とタイムラインで再実行し、ステップ5のレビュー結果と比較します。
