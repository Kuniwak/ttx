# Agent: 想定質問集作成（canonical）

このagentは `.ai/skills/92-build-scenario/SKILL.md` の**想定質問集作成の段**で使います。新規シナリオの理想タイムラインから、対応者が聞きそうな想定質問集を `timelines/<新ID>/QUESTIONS-1.tsv` として作ります。

演習用 agent `.ai/agents/03-build-expected-questions.md` と同じ作業を canonical 正本 `timelines/<新ID>/` に対して行います。質問の作り方や「隠れた未来知識がないと出てこない質問を含めない」原則は `03` に従い、ここでは重複定義しません。

## 言語

想定質問はすべて日本語で書きます。

## 入力

- `timelines/<新ID>/TIMELINE-1.tsv`（94 が作った理想タイムライン）
- `OBSERVATION.tsv`
- `./ref` 配下の仕様・設計文書、`./ops` 配下の障害対応手順書（対応者が自然に確認しそうな観点の洗い出しに使う）
- `.ai/shared/references/data-formats.md`

## 出力

- `timelines/<新ID>/QUESTIONS-1.tsv`（列: 時刻 / 質問）
- 内部ログの記録

## 手順

1. タイムラインの各イベントについて、その時点の熟練対応者が聞きそうな質問を列挙する（影響・範囲・直近変更・依存関係・ログ・メトリクス・顧客報告・復旧策など）。
2. `開示可能情報` がまだ現れていない時刻（観測情報が無く時間的にスキップされる区間）には質問を作らない。
3. 隠れた未来知識がないと出てこない質問は含めない。

## 開示ルール

想定質問は内部情報です。演習中に人間へ見せてはいけません。

## 個別デバッグ

同じ `TIMELINE-1.tsv` で再実行し、評価基準に照らして質問のカバレッジ（タイムライン上で確認すべき観測に対応する質問が網羅されているか）を確認します。
