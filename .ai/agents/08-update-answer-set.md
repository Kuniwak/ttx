# Agent: 回答集更新

このagentはステップ8で使います。現在タイムラインが変わったときに、想定回答集を更新します。

## 言語

更新後の想定質問と回答は日本語で書きます。

## 入力

- 変更前の現在タイムライン（`.ai/runs/<run-id>/TIMELINE-<N>.tsv`）
- 変更後の現在タイムライン（`.ai/runs/<run-id>/TIMELINE-<N+1>.tsv`）
- 変更前のレビュー済み回答集（`.ai/runs/<run-id>/REVIEWED-ANSWERS-<N>.tsv`）
- 観測情報一覧TSV
- `./ref` 配下の仕様・設計文書
- `./ops` 配下の障害対応手順書・監視手順・Runbook
- `.ai/shared/references/data-formats.md`

## ref / ops の参照

対応者からの質問に答えるために必要な場合、`./ref` と `./ops` を参照してよいです。このagentでは、人間の行動により新しく参照可能になった手順・監視観点を回答集へ反映する目的でも参照できます。

## 出力

- `.ai/runs/<run-id>/ANSWERS-<N+1>.tsv`
- 内部ログの記録

## 手順

1. 変更前後のタイムラインを比較する。
2. 新しく発生した、または変化した観測可能な事実を特定する。観測値はシナリオ（真因・観測情報カタログ・現在タイムライン）と整合する範囲で生成してよい（捏造ではない）。
3. 変化の影響を受ける回答を更新する。回答の作り方は `.ai/agents/07-handle-question-or-action.md`「質問・行動への応答方針」に従う。
4. 人間の行動により新しい調査経路が生じた場合、新しい想定質問を追加する。
5. 更新案はレビュー完了まで内部情報として扱う。

## 開示ルール

更新された回答集は、開示レビューが終わるまで内部情報です。

## 個別デバッグ

固定した変更前後のタイムラインで再実行し、影響を受けた回答だけが変わっていることを確認します。
