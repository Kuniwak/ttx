# インシデント対応マニュアル

本マニュアルは、対象システム（OpenTelemetry Demo）で発生した障害に対する**標準的なインシデント対応の枠組み**を定めます。Google の SRE Book / SRE Workbook が示すインシデント管理（Incident Command System、Severity、エスカレーション、コミュニケーション、ポストモーテム文化）を参照して独自に記述したものです（条文の転載ではありません）。

出典: <https://sre.google/sre-book/managing-incidents/> / <https://sre.google/workbook/incident-response/>

## 役割（インシデント対応体制）

インシデント時は、対応者が以下の役割を明示的に立てて指揮系統を一本化します。小規模なら1人が兼務し、規模に応じて分割します。`SCENARIO-LIST.tsv` の `初動対応部署`・タイムラインの `想定対応部署` では、次の正規名を使います。

| 役割（正規名） | 責務 |
| --- | --- |
| `インシデントコマンダー` | 指揮を執り、意思決定と役割分担を行う。技術作業そのものは担わない。 |
| `SRE` | オンコールの一次対応。検知・トリアージ・調査・復旧オペレーションを実行する。 |
| `開発` | 影響を受けたサービスのオーナー（Service Owner）。原因の特定・修正・ロールバックを担う。 |
| `カスタマーサポート` | 顧客影響の把握と顧客向け案内・問い合わせ対応。 |
| `広報` | 対外周知・ステータスページ・社内外コミュニケーションの窓口。 |

## Severity（重大度）

| 重大度 | 目安 | 例 |
| --- | --- | --- |
| `SEV1` | 主要機能が広範に停止、または重大なデータ毀損。即時の全社対応が必要。 | 注文（チェックアウト）が全面的に不可、決済の広範な失敗、データ消失。 |
| `SEV2` | 一部機能の障害や顕著な性能劣化。顧客影響はあるが回避策がある／範囲が限定的。 | 一部商品ページの失敗、特定機能の劣化、リカバリ可能な遅延。 |
| `SEV3` | 軽微・限定的。顧客影響はほぼ無いか、内部処理の遅延にとどまる。 | 非クリティカルな非同期処理の遅延、軽微なUI不具合。 |

重大度は**顧客影響の範囲・継続時間・データ毀損の有無**で判定します。判断に迷う場合は高め（保守的）に置き、状況が分かり次第見直します。

## エスカレーション

- `SEV1`: ただちに `インシデントコマンダー` を招集し、経営層・関係チームへ第一報を出す。定期的なステータス更新（社内告知・ステータスページ）を継続する。
- `SEV2`: 影響サービスの `開発` オンコールへエスカレーションし、必要に応じて `インシデントコマンダー` を立てる。
- `SEV3`: 通常のオンコール対応で処理し、特別なエスカレーションは不要。

## 対応の流れ

1. **検知**: 監視アラート（Prometheus/Grafana）、ユーザー問い合わせ、ダッシュボードの異常などで気づく。
2. **トリアージ／障害認定**: 障害として扱うか判断し、暫定の Severity を置く。`インシデントコマンダー` と記録担当を決める。
3. **影響緩和（mitigation first）**: 原因究明より先に、顧客影響を下げる暫定策（フラグ切り戻し、直近変更のロールバック、トラフィック制御など）を優先する。
4. **調査・原因特定**: メトリクスとトレースを突き合わせ、支持情報と反証情報を分けて切り分ける。
5. **復旧**: 暫定復旧 → 安定確認 → 恒久対応。
6. **収束・記録**: 影響時間・件数・未解決事項を整理し、改善アクション（オーナー・期限・優先度・完了条件）を登録する。

## コミュニケーション

- 指揮系統・記録正本・次回更新時刻を明示し、関係者が同じ情報を見られるようにする。
- 顧客向けには、確定した事実と回避策のみを伝え、内部の推測（未確定の原因・内部実装の詳細）は出さない。

## 個人情報（PII）の取り扱い

セキュリティ／データ事案では、PII を含む情報は限定共有チャネルでのみ扱い、最小権限でアクセスし、PII を含む情報と含まない情報を分離して取り扱います。

## ポストモーテム

インシデント後は**非難しない（blameless）ポストモーテム**を作成します。時系列、影響、検知・対応の評価、根本原因、再発防止の改善アクションを記録し、仕組みの改善に繋げます（個人の責任追及はしません）。
